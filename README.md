# JCees Forms Developer Guide

Build and manage forms in one place, then integrate them into your application using React, Vue, Next.js, Nuxt or Vanilla JavaScript.

JCees Forms is a developer-friendly form builder that keeps developers in control of the implementation, while giving marketing teams the freedom to create and manage forms without requiring code changes for every update.

**Build once. Manage without code.**

## Supported frameworks

JCees Forms can be integrated into:

- React
- Vue
- Next.js
- Nuxt
- Vanilla JavaScript

## Why JCees Forms?

### Built for developers

Keep control over the integration, styling and behaviour of forms within your application.

### Easy for marketing teams

Once integrated, forms can be created and updated through the visual builder without involving a developer in every content, field or validation change.

### Custom styling

Use your own CSS to make forms fit seamlessly into your website or application.

### Smart form logic

Configure validation and conditional form flows without hardcoding every change.

### Integrations

Connect form submissions to your existing workflows using webhooks and notifications.

## How it works

1. Create and configure your form in JCees Forms.
2. Integrate the form into your application.
3. Style and control the implementation within your project.
4. Manage future form changes centrally through JCees Forms.

This keeps the technical implementation in the hands of developers while allowing forms to evolve without every update becoming a development task.
